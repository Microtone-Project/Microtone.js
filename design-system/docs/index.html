Microtone design system

The tracker's interface is a working instrument panel: dense, flat, hairline-ruled, lit by a few saturated inks that each mean one thing. Everything on this page is drawn by the app's own stylesheet and components, so switching the theme above shows exactly what the app shows.

README.mdThe rules and the reasons — start here. tokens.jsonEvery token, per theme, with contrast. Generated from the stylesheet. components.jsonThe component library and the rules, as data. notes.jsonWhat each token is for; the text styles.

Rules

Colour

Click a name to copy var(--name). The large swatch is the live token in the current theme; the four small ones are dark, dim, light and warmth.

Contrast

WCAG 2 ratios, computed from the tokens. Text needs 4.5:1 (3:1 at 24px and up, and for control borders); the source's failing pairs are kept and flagged, not hidden.
